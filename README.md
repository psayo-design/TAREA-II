# PROYECTO: Operaciones Matemáticas con Funciones Recursivas

## Descripción General

Este proyecto consiste en el desarrollo de un programa interactivo en Python que implementa diversas operaciones matemáticas utilizando **funciones recursivas**.
El programa funciona mediante una interfaz de línea de comandos (CLI), permitiendo al usuario seleccionar diferentes operaciones desde un menú interactivo.
El objetivo académico del proyecto es demostrar la correcta implementación del concepto de **recursividad**, el manejo de errores y una estructura modular profesional en Python.

## Objetivos del Proyecto

- Implementar funciones matemáticas utilizando recursividad.
- Aplicar buenas prácticas de programación.
- Incorporar manejo de errores con `try-except`.
- Diseñar un programa estructurado y modular.
- Crear documentación clara para su ejecución y evaluación.

## Requisitos del Sistema

Para ejecutar el programa, el equipo debe contar con:

- Python 3.8 o superior
- Sistema operativo:
  - Windows
  - Linux
  - macOS
- Terminal o consola de comandos

## Menú con Funciones:

1.  Convertir a Binario Convierte un número entero a binario usando
    recursividad.

2.  Contar Dígitos Cuenta la cantidad de dígitos de un número entero.

3.  Raíz Cuadrada Entera Calcula la raíz cuadrada entera usando una
    función auxiliar recursiva.

4.  Convertir Número Romano a Decimal Convierte números romanos a
    sistema decimal aplicando reglas de suma y sustracción.

5.  Suma de Números Enteros Suma todos los números desde 0 hasta un
    número entero positivo dado.
